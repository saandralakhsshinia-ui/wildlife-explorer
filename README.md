# 🌿 Wildlife Explorer

> *A cinematic, interactive wildlife education experience — inspired by National Geographic.*

![Status](https://img.shields.io/badge/Status-Live-brightgreen) ![Built With](https://img.shields.io/badge/Built%20With-HTML%2FCSS%2FJS-gold) ![Three.js](https://img.shields.io/badge/3D-Three.js-blue)

## 🎬 Overview

**Wildlife Explorer** is a premium, single-page interactive web experience designed to educate and inspire through the beauty of the natural world. Built entirely with vanilla HTML, CSS, and JavaScript, it delivers a cinematic, documentary-grade interface with immersive animations, 3D effects, and real wildlife data — no frameworks required.

---

## ✨ Key Features

- 🦁 **Animal Showcase** — Circular interactive layout with hover glow and click-to-reveal info panels
- 🌍 **Interactive 3D Globe** — Rotatable globe highlighting top 5 countries per animal with population and conservation data
- 🧊 **3D Habitat Cube** — Rotating Three.js cube across 6 ecosystems: Forest, Desert, Ocean, Arctic, Mountains, Jungle
- 📜 **Conservation Timeline** — Scroll-driven history from 1800 to 2024 with cinematic animations
- 🃏 **Glassmorphism Cards** — 3D tilt-on-hover animal cards with modal popups
- 🖼️ **Rotating Gallery** — Auto-rotating wildlife images with fade and slide transitions
- 🌴 **Atmospheric Effects** — Parallax layers, floating particles, light rays, custom paw cursor

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 / CSS3 | Structure & styling |
| Vanilla JavaScript | Interactivity & animations |
| Three.js (r128) | 3D globe & habitat cube |
| Google Fonts | Cinzel Decorative, Raleway |
| Canvas API | Custom globe rendering |

## 🎨 Design Language

- **Color Palette:** Deep forest greens, rich blacks, gold accents
- **Style:** Glassmorphism, cinematic lighting, soft glow effects
- **Typography:** Cinzel Decorative (display) + Raleway (body)
- **Motion:** Scroll-based reveals, parallax layers, 3D transforms
